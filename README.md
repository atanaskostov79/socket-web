# Сокет уеб сървър

Ученически проект: малък уеб сървър на Python, написан със стандартната библиотека `socket`. Няма Flask, Django или друг готов уеб фреймуърк. Сървърът приема HTTP заявки и връща две HTML страници.

Сървърът слуша на **един адрес и един порт**: `127.0.0.1:8080`.

## Изисквания

- Python 3.10 или по-нов (ползват се типови анотации и `pathlib`)
- Браузър на същата машина

Не се инсталират пакети и не трябва виртуална среда. Всичко идва със самия Python.

## Структура

```text
socket-web/
├── README.md          тази документация
├── server.py          сървърът
└── pages/
    ├── index.html     начална страница
    └── about.html     втора страница
```

## Стартиране

Отвори терминал в папката `socket-web` и пусни:

```bash
python3 server.py
```

В терминала се появява:

```text
Сървърът слуша на http://127.0.0.1:8080
Страници: /  и  /about
Спри с Ctrl+C
```

Отвори в браузъра:

| Адрес | Файл | Какво показва |
| --- | --- | --- |
| http://127.0.0.1:8080/ | `pages/index.html` | начална страница |
| http://127.0.0.1:8080/index.html | `pages/index.html` | същата начална страница |
| http://127.0.0.1:8080/about | `pages/about.html` | втора страница |
| http://127.0.0.1:8080/about.html | `pages/about.html` | същата втора страница |

Двете страници имат линк една към друга.

Спиране: в терминала натисни `Ctrl+C`. Сървърът отпечатва `Спрян.` и излиза.

## Как работи

При всяко отваряне на страница се случва следното:

1. `socket()` създава TCP сокет за IPv4 (`AF_INET`, `SOCK_STREAM`).
2. `bind()` го закача към `127.0.0.1` и порт `8080`.
3. `listen()` го оставя да чака връзки.
4. `accept()` приема една връзка от браузъра.
5. `recv()` чете HTTP заявката, докато стигне празния ред след заглавната част.
6. Програмата гледа метода и пътя и избира файл от `pages/`.
7. `sendall()` изпраща HTTP отговор: статус, заглавни редове и HTML.
8. Връзката се затваря. Сървърният сокет остава на порт `8080` и чака следващата заявка.

Заявките се обработват една след друга. Докато една се чете и отговаря, следващите чакат в опашка (до 5).

## Портът

Сървърът има един порт: **8080**.

Браузърът при свързване си избира отделен временен порт (например 39874). Този порт е на клиента и се сменя при всяка нова връзка. Той не е втори порт на сървъра. В лога се печата само сървърният адрес, за да се вижда, че всички заявки минават през `127.0.0.1:8080`:

```text
127.0.0.1:8080  GET / HTTP/1.1
127.0.0.1:8080  GET /about HTTP/1.1
```

`127.0.0.1` означава „само този компютър“. От друга машина в мрежата адресът не се отваря.

## Формат на заявката

Браузърът изпраща текст от този вид:

```text
GET /about HTTP/1.1
Host: 127.0.0.1:8080
Connection: close

```

Първият ред има три части:

- `GET` — метод. Сървърът приема само GET.
- `/about` — пътят, по който се избира страницата.
- `HTTP/1.1` — версията на протокола.

Заглавните редове следват до празен ред (`\r\n\r\n`). Програмата ползва само първия ред.

## Формат на отговора

Успешен отговор изглежда така:

```text
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Content-Length: 502
Connection: close

<!DOCTYPE html>
...
```

- Първият ред е версия и статус.
- `Content-Type` казва, че тялото е HTML в UTF-8.
- `Content-Length` е броят байтове на тялото.
- `Connection: close` затваря TCP връзката след отговора.
- Празният ред отделя заглавната част от HTML файла.

## Кодове за отговор

| Код | Кога |
| --- | --- |
| 200 OK | пътят е в таблицата и файлът съществува |
| 400 Bad Request | първият ред не се разчита като метод, път и версия |
| 404 Not Found | непознат път, или файлът липсва от `pages/` |
| 405 Method Not Allowed | методът не е GET (например POST) |

## Основни части в `server.py`

| Име | Роля |
| --- | --- |
| `HOST`, `PORT` | единственият адрес, на който се слуша |
| `PAGES` | папката с HTML файловете |
| `ROUTES` | съответствие между URL път и име на файл |
| `http_response()` | сглобява заглавната част и тялото |
| `handle_request()` | решава кой файл или коя грешка да върне |
| `serve()` | създава сокета и върти цикъла за връзки |

`SO_REUSEADDR` позволява портът да се ползва отново веднага след спиране. Ако все пак се появи `OSError: [Errno 98] Address already in use`, вече има пуснат `python3 server.py`. Спри го с `Ctrl+C` в неговия терминал и стартирай отново.

## Ограничения

- Само две страници, описани в `ROUTES`.
- Само метод GET.
- Няма картинки, CSS файлове и JavaScript файлове като отделни заявки. Стилът е вътре в HTML.
- Няма HTTPS.
- Една връзка се обработва в даден момент.
- Слуша само на localhost.
